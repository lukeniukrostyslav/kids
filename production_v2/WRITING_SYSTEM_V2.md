# V2 — СИСТЕМА НАПИСАНИЯ РОМАНА

## Назначение
Это обязательная производственная система для «Атлас исчезнувших дней».

Предыдущие рукописные главы удалены. Новая проза начинается с нуля.

## Главный принцип
Не копировать Harry Potter. Использовать только абстрактные драматургические механизмы, выявленные при чтении загруженного EPUB.

Каждая глава пишется только после:
1. анализа соответствующего образца/механизмов;
2. составления карты сцен;
3. определения функции каждой сцены;
4. проверки связи с архитектурой нашего романа;
5. написания;
6. отдельного QA;
7. проверки на искусственную дробность прозы.

## ЖЁСТКИЙ ПРОЗОВЫЙ ФИЛЬТР

Запрещено:
- обычные абзацы по 1–2 предложения без художественной необходимости;
- последовательности вида «Имя. Адрес. Дата.»;
- постоянное дробление мысли на отдельные строки;
- диалог в форме анкеты «вопрос → ответ → вопрос → ответ»;
- объяснение мира через длинные справочные реплики;
- искусственное растягивание текста ради количества слов.

Норма:
- полноценные смысловые абзацы;
- действие, наблюдение, реакция и диалог соединяются в естественный поток;
- короткий абзац используется только для ритмического/драматического акцента;
- каждая сцена имеет физическое пространство;
- персонажи что-то делают во время разговора;
- реплика должна либо раскрывать характер, либо менять ситуацию, либо создавать подтекст, либо давать необходимую информацию, либо менять отношения.

## СЦЕНА

Для каждой сцены фиксируем:
- место;
- время;
- POV;
- вход героя в сцену;
- исходное состояние;
- цель;
- препятствие;
- действие;
- взаимодействие;
- новая информация;
- эмоциональный сдвиг;
- изменение отношений;
- выход из сцены;
- крючок следующей сцены.

## МОДЕЛЬ ГЛАВЫ

Глава не обязана иметь столько же сцен, сколько образец.

Сначала определяется:
- сколько самостоятельных драматических единиц нужно нашей главе;
- зачем каждая существует;
- где находятся переходы;
- где первый интерес;
- где усложнение;
- где эмоциональный пик;
- где открытый вопрос/крючок.

Нельзя механически переносить структуру чужой книги.

## ДИАЛОГ

Диалог проверяется по пяти уровням:
1. буквальный смысл;
2. скрытая цель;
3. эмоциональное состояние;
4. действие/поведение между репликами;
5. изменение ситуации после разговора.

Если персонажи просто обмениваются информацией, сцена переписывается.

## ПАРАГРАФ

Каждый абзац должен быть самостоятельной смысловой единицей.

Связанные действия и мысли объединяются.

Проверка:
- можно ли естественно прочитать абзац вслух;
- есть ли в нём законченная мысль;
- не раздроблен ли он искусственно;
- не превращён ли внутренний монолог в список;
- не превращён ли диалог в сценарий.

## РИТМ

Чередуем:
наблюдение → действие → диалог → реакция → деталь → осложнение.

Не допускаем:
объяснение → объяснение → объяснение.

## КОНТРОЛЬ ПЕРЕД ПУБЛИКАЦИЕЙ ГЛАВЫ

1. Карта сцен сохранена.
2. Все сцены имеют функцию.
3. Каждый переход причинен.
4. Нет искусственной дробности.
5. Нет пустых диалогов.
6. Нет копирования конкретных сцен/персонажей/фраз Harry Potter.
7. Все события соответствуют A0–A15.
8. Количество слов находится в рабочем диапазоне, но не достигается искусственным добавлением.
9. Глава заканчивается изменением ситуации или сильным вопросом.
10. Только после этого глава сохраняется как финальная.

## ПРОИЗВОДСТВЕННЫЙ ЦИКЛ

ANALYZE → SCENE MAP → WRITE → PROSE QA → STORY QA → ORIGINALITY QA → SAVE → NEXT CHAPTER.

Нельзя переходить к следующей главе, пока предыдущая не прошла все проверки.
