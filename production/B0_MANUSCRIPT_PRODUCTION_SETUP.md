# B0 — ПОДГОТОВКА РУКОПИСИ К ПРОИЗВОДСТВУ

**Проект:** KIDS / «Атлас исчезнувших дней»  
**Статус:** B0 — 100%  
**Архитектура:** A0–A15 — 100%  
**Исследование:** R1–R13 — 100%  
**Механизмы:** M1–M2806 — 100%  
**Проза:** 0%

## 1. Назначение

B0 переводит закрытую архитектуру в производственный режим.

Начиная с B1, главы пишутся последовательно и проходят отдельный QA.

## 2. Источники перед каждой главой

Перед написанием соответствующей главы необходимо сверяться с:

- A11 — полный сюжет;
- A12 — улики и предвосхищение;
- A13 — ритм;
- A14 — Character Registry;
- A15 — финальный аудит;
- соответствующими материалами R1–R13;
- загруженным EPUB Harry Potter только как исследовательским источником общих литературных механизмов, без копирования конкретных элементов.

Исследовательский материал не должен подменять оригинальную архитектуру.

## 3. Правило производства

Пишется одна глава за раз.

После каждой главы фиксируются:

- номер главы;
- название;
- количество слов;
- накопленное количество слов;
- среднее количество слов на главу;
- прогноз общего объёма;
- персонажи;
- новые улики;
- раскрытая информация;
- эмоциональное изменение;
- изменения отношений;
- последствия;
- открытые вопросы.

## 4. Целевой объём

Ориентир всего романа:

**≈ 90 000 слов.**

Рабочий диапазон:

**85 000–95 000 слов.**

Ориентиры главы:

- обычная: 2300–2700;
- важная: 2500–2900;
- кульминационная: 2700–3200;
- переходная: 2000–2400.

Количество слов не является целью само по себе. Если сцена завершена раньше, текст не растягивается искусственно.

## 5. Формат прозы

Запрещается:

- разбивать нормальный абзац на строки по одному-двум словам;
- искусственно создавать «поэтические» разрывы;
- использовать чрезмерно короткие абзацы без художественной причины;
- перегружать текст пустыми метафорами;
- объяснять вместо показа там, где сцена может показать действие.

Текст должен состоять из полноценных читаемых абзацев.

## 6. Контроль сцены

Перед завершением каждой сцены проверяется:

1. место;
2. физическое присутствие;
3. цель;
4. препятствие;
5. действие;
6. конкретная сенсорная деталь;
7. новая информация;
8. эмоциональная реакция;
9. изменение отношений или состояния;
10. причинная связь со следующей сценой.

## 7. Контроль персонажей

Каждый персонаж должен действовать из своей мотивации.

Нельзя:

- заставлять персонажа делать что-то только ради удобства сюжета;
- давать второстепенному персонажу чужую функцию без причины;
- забывать ранее установленный секрет;
- менять характер без события, которое объясняет изменение.

## 8. Контроль тайны

Для каждой крупной загадки проверяется:

**улика → гипотеза → проверка → частичный ответ → новое осложнение → раскрытие → переосмысление.**

Информация не появляется из ниоткуда.

## 9. Контроль оригинальности

При каждой главе дополнительно проверяется:

- нет ли слишком близкого соответствия конкретной сцене исследованных произведений;
- нет ли прямого переноса знакомой сюжетной функции с заменой имени;
- нет ли копирования характерной последовательности событий;
- нет ли имитации авторской манеры;
- сохраняется ли самостоятельность мира, персонажей, конфликта и языка.

Общие механизмы могут использоваться.

Конкретные узнаваемые элементы — нет.

## 10. Эмоциональный контроль

После каждой главы фиксируется:

**что герой чувствовал в начале → что произошло → что он чувствует в конце → почему состояние изменилось.**

Эмоциональные изменения должны быть заработаны сценами.

## 11. Непрерывность

После каждой главы проверяется:

- возраст;
- время;
- место;
- предметы;
- знания персонажей;
- физическое состояние;
- отношения;
- предыдущие решения;
- открытые вопросы;
- обещанные улики.

## 12. Производственный цикл

**B1 — Глава 1**

После B1:

**QA → исправления → фиксация статистики → GitHub → переход к B2.**

Один завершённый блок не считается следующим блоком автоматически: сначала проверяется качество.
