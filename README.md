# KIDS — ORIGINAL NOVEL RESEARCH LAB

Цель проекта — глубоко исследовать механизмы, которые делают детско-подростковое приключенческое фэнтези захватывающим, а затем на их основе создать полностью оригинальный роман.

## Основные источники

1. Загруженный EPUB: «Гарри Поттер и философский камень» — используется как первичный материал для анализа структуры, сцен, персонажей, эмоций, конфликтов, тайны, юмора, ритма и приёмов повествования.
2. Внешние источники — для исследования рецепции, издательской истории и причин коммерческого/читательского успеха.
3. Собственные документы проекта — для превращения наблюдений в оригинальные литературные принципы.

## Правило оригинальности

Мы не копируем текст, диалоги, персонажей, названия, мир, конкретные сцены или сюжетные конструкции. Извлекаются только обобщённые литературные механизмы и проверяются на возможность самостоятельного применения.

## Структура исследования

- R0 — протокол исследования
- R1 — покадровый/посценовый анализ романа
- R2 — персонажная система
- R3 — эмоциональная система
- R4 — конфликты
- R5 — мир
- R6 — игры и соревнования
- R7 — юмор
- R8 — тайны и загадки
- R9 — предвосхищение
- R10 — ритм
- R11 — читательское напряжение
- R12 — внешнее исследование успеха
- R13 — библиотека оригинальных приёмов
- R14 — создание собственного романа

Исследование выполняется последовательно. Процент блока повышается только после фактического выполнения работы.
