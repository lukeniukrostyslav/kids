# 2. Главная функция главы

Глава 7 переводит героя из статуса:

**«новичок, который приехал в новый мир»**

в статус:

**«член конкретного сообщества внутри этого мира».**

До этого Гарри получил доступ к магическому миру, но ещё не имел собственного места в нём.

Церемония делает сразу несколько вещей:

1. создаёт социальную карту школы;
2. распределяет первокурсников;
3. формирует будущие группы;
4. превращает абстрактную школу в систему принадлежности;
5. создаёт внутренний выбор Гарри;
6. вводит соревнование факультетов;
7. показывает, что выбор может зависеть от характера;
8. связывает решение с будущими отношениями;
9. вводит множество второстепенных учеников;
10. заканчивает главу первой полноценной жизнью внутри школы.

Официальный HarryPotter.com объединяет главы 7–9 под темой «Welcome to Hogwarts» и отдельно выделяет Sorting Ceremony как один из центральных элементов этого этапа. citeturn0search6

# 3. Эмоциональная дуга

**усталость → тревога → страх оценки → ожидание → удивление → напряжение → облегчение → принадлежность → голод → удовольствие → любопытство → тревога → тайна → юмор → усталость → безопасность.**

Очень важный момент:

церемония начинается как потенциальная угроза.

Гарри не знает правил.

Он боится:

- провала;
- публичного унижения;
- неправильного выбора;
- отсутствия места;
- Слизерина;
- того, что он окажется недостаточно хорош.

Но заканчивается глава:

**еда → смех → общая гостиная → спальня.**

То есть эмоциональная траектория идёт от **«куда меня возьмут?»** к **«вот где теперь моё место».**

# 4. Посценовый разбор

## Сцена 1. МакГонагалл как пороговый персонаж

Дверь открывается, появляется МакГонагалл.

Она сразу воспринимается Гарри как строгая фигура.

Это первый взрослый, который не объясняет мир мягко и не пытается понравиться.

**M119 — персонаж через первое телесно-эмоциональное впечатление.**

---

## Сцена 2. Первый взгляд на внутреннее пространство школы

Гарри проходит огромный зал.

Размер здания показывает:

**новый мир больше, чем он мог представить.**

Важна масштабная последовательность:

Дурсли → улица → Косой переулок → поезд → замок.

Каждый переход увеличивает мир.

---

## Сцена 3. Голоса за закрытой дверью

Гарри слышит сотни голосов, но ещё не видит школу.

Это создаёт предвосхищение.

**M120 — звук раньше изображения.**

Читатель сначала получает признак большого сообщества, а потом увидит его.

---

## Сцена 4. МакГонагалл объясняет правила

Здесь появляется социальная архитектура факультетов.

Особенно важно понятие:

**факультет = вторая семья.**

То есть распределение — не административная формальность.

Оно определяет:

- где жить;
- с кем проводить время;
- с кем учиться;
- за кого бороться;
- какую идентичность носить.

**M121 — институт как эмоциональная принадлежность.**

---

## Сцена 5. Очки как игровая система

Факультеты получают очки за достижения и теряют их за нарушения.

Это вводит простую игровую экономику.

Сразу появляются:

- награда;
- риск;
- соревнование;
- групповая ответственность;
- будущие конфликты.

**M122 — правила мира превращаются в игровую механику.**

## Сцена 6. Мгновенный статус

МакГонагалл замечает одежду Невилла и грязный нос Рона.

Даже маленькие физические детали показывают состояние персонажей.

**M123 — статус персонажа через внешний беспорядок.**

## Сцена 7. Ожидание в маленькой комнате

Первокурсники изолированы перед входом в Большой зал.

Это пространство ожидания.

Они ещё не принадлежат ни одному факультету.

**M124 — промежуточное пространство для формирования напряжения.**

## Сцена 8. Ложная угроза

Для другого ребёнка распределение было бы просто необычной процедурой.

Для Гарри оно означает:

**«выберут ли меня на этот раз?»**

# 9. Ритм главы

Потом цикл ломается на Гарри:

**имя → шёпот → ожидание → внутренняя дискуссия → выбор → огромная реакция.**

# 13. Что можно перенести в оригинальный роман

Нам особенно ценен принцип:

**ритуал выбора = машина создания социальной структуры.**

Для оригинальной книги это может быть не распределение по факультетам.

Например, героев можно распределять:

- по ролям внутри организации;
- по специализациям;
- по командам;
- по маршрутам;
- по уровням допуска;
- по типам дара;
- по философским принципам;
- по профессиональным функциям;
- по испытаниям.

Но система должна делать то же самое:

**дать персонажу место → создать союзников → создать конкурентов → сформировать правила → дать будущие ставки.**
