# 2. ПРОВЕРКА КОНЦЕПЦИИ

**Результат: PASS**

«Атлас исчезнувших дней» имеет самостоятельный двигатель:

> события могут исчезать из коллективной памяти, сохраняя физические следы.

Главный вопрос:

> что произошло в день, которого официально не существовало, и почему Maya связана с ним?

Концепция не требует магической школы или традиционной системы заклинаний.

# 4. ПРОВЕРКА ТЕМЫ

**Результат: PASS**

Главная тема:

**память формирует личность, но человека определяет не только то, что он помнит, а то, что он выбирает делать с правдой.**

Главный философский конфликт:

**право знать ↔ право забыть.**

Важное условие:

Ни одна сторона не должна быть представлена абсолютно правильной.

**Результат: PASS**

- имеет конкретную цель;

- имеет слабость;

- получает последствия;
- не является всезнающей;
- не является избранной;
- не обладает решением всех проблем;
- должна принимать моральное решение.

Арка:

**наблюдение → поиск → подозрение → одержимость → вина → понимание → выбор → ответственность.**

# 12. ПРОВЕРКА УЛИК

**Результат: PASS**

Основная модель:

**улика → подтверждение → ложная интерпретация → дополнительная улика → раскрытие → переосмысление.**

Это позволяет читателю строить собственную гипотезу.

Важные правила:

- информация не появляется из ниоткуда;
- существенные ответы получают предварительные следы;
- ложные версии имеют реальные объяснения;
- детали должны менять смысл после раскрытия.

Каждый крупный этап возникает из предыдущего.
