# A13 — РИТМ И ТЕМП РОМАНА

**Проект:** KIDS / «Атлас исчезнувших дней»  
**Статус:** A13 — 100%

## 1. Главный принцип

Роман не должен идти на одной скорости.

Нужна волна:

**спокойствие → любопытство → движение → юмор → напряжение → открытие → эмоциональная пауза → новая угроза.**

Ритм меняется вместе с эмоциональным состоянием героев.

## 2. Базовая единица ритма

Каждая глава должна иметь:

1. конкретное место;
2. цель сцены;
3. препятствие;
4. действие;
5. новую информацию;
6. эмоциональное изменение;
7. крючок или открытый вопрос.

Не каждая глава обязана заканчиваться опасностью.

## 3. Типы сцен

### A — Повседневность

Школа, дом, прогулка, разговор, еда, транспорт.

Функция: показать нормальную жизнь.

### B — Исследование

Документы, карты, фотографии, архивы.

Функция: двигать загадку.

### C — Отношения

Дружба, спор, доверие, семейные разговоры.

Функция: эмоциональное развитие.

### D — Юмор

Комические ситуации, характерные реакции, дружеские сцены.

Функция: эмоциональное дыхание.

### E — Опасность

Слежка, риск, закрытое место, конфликт.

Функция: повышение ставок.

### F — Открытие

Новая информация меняет понимание прошлого.

Функция: сюжетный поворот.

### G — Последствие

Герои сталкиваются с результатом предыдущего решения.

Функция: причинность.

## 4. Ритм первой трети

Главы 1–7:

**A → B → C → D → B → F → C**

Начало не должно сразу превращаться в погоню.

Читатель сначала должен почувствовать обычную жизнь Maya.

Затем невозможное постепенно вторгается в неё.

## 5. Ритм второй трети

Главы 8–14:

**B → C → B → E → D → E → G**

Расследование становится активнее.

Появляется Theo.

Появляется Nikita.

Возникают первые реальные последствия.

## 6. Ритм расширения

Главы 15–22:

**F → B → F → C → B → E → E → G**

Масштаб увеличивается.

Появляется Архив Тишины.

Адриан начинает воздействовать на героев.

Команда впервые серьёзно рискует распасться.

## 7. Ритм кризиса

Главы 23–29:

**C → E → E → G → C → F → F**

Здесь эмоциональная нагрузка выше.

Необходимо давать короткие паузы между тяжёлыми раскрытиями.

## 8. Ритм финала

Главы 30–36:

**E → C → E → F → F → C → F**

Финал ускоряется, но не превращается в непрерывный экшен.

Последние главы должны сочетать:

- действие;
- раскрытие;
- эмоциональные решения;
- последствия.

## 9. Правило ускорения

Когда герой приближается к важному открытию:

- сцены могут становиться короче;
- действия — конкретнее;
- диалоги — плотнее;
- переходы — быстрее.

Но скорость не должна уменьшать ясность.

## 10. Правило замедления

После крупного открытия нужна эмоциональная обработка.

Например:

**опасность → открытие → тишина → реакция Maya → разговор → новое решение.**

Не перескакивать сразу к следующему экшену.

## 11. Юмор как дыхание

Юмор особенно нужен:

- после тяжёлой сцены;
- перед первым серьёзным риском;
- внутри дружеских сцен;
- во время обычной жизни.

Но юмор должен исходить из характера.

Leo не должен превращаться в постоянный источник шуток.

## 12. Контраст

Сильные сцены работают лучше, если рядом есть контраст.

Например:

**обычный школьный день → фотография, которой не должно существовать.**

Или:

**смешной разговор → внезапное обнаружение старой даты.**

## 13. Ритм расследования

Расследование не должно постоянно давать ответы.

Цикл:

**вопрос → след → гипотеза → проверка → частичный ответ → новый вопрос.**

Иногда герои должны ошибаться.

## 14. Ритм раскрытия

Большие ответы распределяются.

Не раскрывать одновременно:

- историю отца;
- мать;
- Elena;
- Архив;
- Адриана;
- эксперимент.

Каждый ответ должен менять значение предыдущих событий.

## 15. Мини-крючки

Внутри главы могут быть:

- странная деталь;
- необычная реакция;
- новый предмет;
- противоречие;
- недосказанная фраза;
- изменение поведения.

Мини-крючок не обязан быть клиффхэнгером.

## 16. Крючок конца главы

Конец главы должен делать одно из четырёх:

1. задавать вопрос;
2. давать неожиданную информацию;
3. менять цель;
4. создавать новое препятствие.

Не обязательно заканчивать каждую главу угрозой.

## 17. Большие точки притяжения

Предварительные:

- имя Maya в атласе;
- первая фотография;
- реакция матери;
- появление Theo;
- компас;
- Nikita;
- вторая исчезнувшая дата;
- Elena;
- отец;
- Архив;
- Adrian;
- кризис команды;
- правда матери;
- история эксперимента;
- финальный выбор.

## 18. Темп персонажей

Разные персонажи должны создавать разный темп.

Maya:

быстро переходит от наблюдения к действию.

Amina:

замедляет сцену проверкой.

Leo:

ускоряет социальное взаимодействие.

Theo:

создаёт паузы и скрытую информацию.

Nikita:

создаёт резкие изменения направления.

Это позволяет управлять темпом через персонажей, а не только через действие.

## 19. Диалоговый ритм

Не каждый разговор должен объяснять сюжет.

Диалог может:

- показывать характер;
- создавать конфликт;
- скрывать информацию;
- давать юмор;
- менять отношения;
- создавать подтекст.

Запрещается превращать персонажей в говорящие справочники.

## 20. Описательный ритм

Описание должно меняться в зависимости от сцены.

В спокойной сцене:

- больше деталей пространства;
- ощущения;
- наблюдения.

В напряжённой:

- конкретные движения;
- короткие сенсорные сигналы;
- внимание к препятствиям.

В эмоциональной:

- тело;
- паузы;
- жесты;
- детали поведения.

## 21. Сенсорный ритм

Каждая важная сцена должна использовать 1–3 работающих сенсорных детали:

- звук;
- запах;
- температура;
- текстура;
- свет;
- движение;
- вкус.

Не перегружать описание всеми пятью чувствами одновременно.

## 22. Ритм главы

Целевой шаблон:

**вход → ориентация → цель → препятствие → развитие → изменение → выход.**

Не каждая глава должна иметь одинаковую длину.

## 23. Длина глав

Рабочая рамка:

- обычная: **2300–2700 слов**;
- важная: **2500–2900 слов**;
- кульминационная: **2700–3200 слов**;
- переходная: **2000–2400 слов**.

Не растягивать главу ради достижения числа.

## 24. Переходы

Переход между главами должен сохранять причинность.

Если глава заканчивается:

**«Нужно проверить архив».**

Следующая глава не должна начинаться через три дня без объяснения.

Переход может быть:

- прямым;
- временным;
- пространственным;
- эмоциональным.

Но читатель должен понимать, почему мы оказались здесь.

## 25. Большая эмоциональная волна

Предварительная кривая:

**любопытство → удивление → веселье → тревога → надежда → сомнение → страх → потеря → понимание → надежда.**

Она не должна быть математически ровной.

## 26. Правило «не перегружать»

Нельзя ставить подряд слишком много:

- крупных открытий;
- опасностей;
- ссор;
- эмоциональных признаний.

После пиков нужен воздух.

## 27. Правило «не провисать»

Если несколько последовательных сцен:

- не дают новой информации;
- не меняют отношения;
- не создают атмосферу;
- не развивают персонажа;
- не двигают действие,

их необходимо объединить, сократить или удалить.

## 28. Ритм середины

Самая опасная зона для провисания — середина.

Поэтому главы 15–22 должны регулярно менять состояние истории:

**новая дата → новый персонаж → новый след → конфликт → новый масштаб → Адриан → разделение.**

## 29. Ритм финала

Финал не должен быть бесконечной гонкой.

Ускорение:

**опасность → решение → действие → открытие → последствия.**

Затем обязательное эмоциональное завершение.

## 30. Эпилог

Эпилог короткий.

Он не должен объяснять следующую книгу.

Он только показывает:

**феномен продолжается.**

## 31. Контроль по каждой главе

Перед написанием каждой главы проверяем:

- темп;
- тип сцены;
- новую информацию;
- эмоциональное изменение;
- сенсорные детали;
- юмор;
- конфликт;
- крючок;
- связь с предыдущей главой;
- связь со следующей;
- отсутствие искусственного растягивания.

## 32. Контроль против однообразия

Нельзя делать:

**расследование → расследование → расследование → расследование.**

Нужно чередовать:

**расследование → отношения → обычная жизнь → юмор → опасность → расследование.**

## 33. Контроль против чрезмерного экшена

Нельзя делать:

**опасность → опасность → опасность → опасность.**

Иначе исчезает ощущение опасности.

Опасность должна быть редкой относительно повседневной жизни, чтобы её появление ощущалось.

## 34. Связь с коммерческим чтением

Читатель должен постоянно чувствовать:

**«я хочу узнать, что дальше».**

Но это достигается не только клиффхэнгерами.

Причины продолжать чтение:

- загадка;
- персонаж;
- отношения;
- атмосфера;
- эмоциональная ставка;
- новый вопрос;
- обещание раскрытия.
